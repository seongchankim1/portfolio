이츠마인 — 실시간 경매 중고거래 플랫폼

2024.07 ~ 2024.08 · 5인 팀 · 백엔드 전담

실시간 경매 기반 중고 거래 플랫폼. 사용자는 경매에 등록하고 최고가 입찰자에게 자동 판매됩니다. 즉시 구매가, 실시간 채팅을 지원하며 경매 중에도 자유롭게 소통할 수 있습니다.

주요 기능

  • 실시간 경매 & 자동 판매
  • 즉시 구매
  • 실시간 채팅
  • Redis 분산 락 (Redisson)
  • RabbitMQ TTL+DLX
  • 카카오 소셜 로그인

기술 스택

  • Java 17 · Spring Boot 3.3 · JPA · QueryDSL
  • AWS EC2 · Docker · ECR · RDS(MariaDB) · ElastiCache(Redis) · CloudFront · S3
  • React · ActiveMQ · Redisson

트러블슈팅

  • 동시성 문제: Redisson FairLock + AOP Annotation으로 분산락 해결 (10명+ 동시 입찰에서 100% 데이터 무결성)
  • 알림 지연: RabbitMQ TTL+DLX 도입으로 응답 시간 800ms → 250ms 개선 (약 60%)
▶️ 시연영상 🔗 GitHub 📄 Notion

Project Manager — 칸반보드 협업 플랫폼

2024.12 ~ 2025.04 · 4인 팀 (BE 2 / FE 2)

Trello/Jira의 복잡함을 줄여 국내 사용자에게 친숙한 UI를 제공합니다. 실시간 초대, 할일 관리, 알림 등 실무 친화적인 기능을 중심으로 구현했습니다.

주요 기능

  • 카카오 소셜 로그인 (JWT)
  • 프로젝트 초대 & 권한 관리
  • 알림 수신함
  • 개인별 진행도 관리

기술 스택

  • Java 17 · Spring Boot 3.3 · JPA · QueryDSL
  • Google Cloud (Compute Engine · Cloud SQL(MySQL) · GCS)
  • Docker · GitHub Actions CI/CD · Redis
  • React

트러블슈팅

  • 쿼리 최적화: 복합 인덱스 + QueryDSL로 1,000만+ User 조회 2~3ms 달성
  • 데이터 파티셔닝: MySQL 월별 파티션으로 조회 성능 50%+ 개선, 0.1초 내 대량 삭제

커뮤니티 프로젝트 — 셀럽 패션 정보 플랫폼

2024.10 ~ 2024.12 · 4인 팀 · 백엔드 전담

유명인 착장 정보를 공유하고 확인하는 커뮤니티형 플랫폼. 이미지 클릭 기반 상품 태깅, 백오피스 통계 대시보드, 다국어 지원을 제공합니다.

주요 기능

  • 상품 정보 태깅 (좌표 기반)
  • 게시글 & 질문 게시판
  • 백오피스 통계 대시보드
  • 다국어 지원 (KR/EN)
  • Redis 실시간 인기 게시글

기술 스택

  • AWS Lightsail · WordPress (PHP) · MySQL · Redis
  • Polylang (다국어)

트러블슈팅

  • 페이징 개선: 로우셋 페이징 + @Cacheable로 응답 시간 1.5초 → 0.5초
  • CQRS 도입: 읽기/쓰기 DB 분리로 읽기 응답 40% 단축, 처리량 30%+ 개선
